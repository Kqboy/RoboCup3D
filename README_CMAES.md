# CMA-ES 踢球参数优化 (Kick Parameter Optimization with CMA-ES)

本项目利用 CMA-ES (Covariance Matrix Adaptation Evolution Strategy) 进化算法来优化机器人的踢球动作参数。代码位于 `优化_cma_train_t长踢的定位和bias.py`。

## 功能概述

该脚本旨在自动调整机器人的踢球参数，以提高踢球的准确性和距离。它通过不断迭代生成新的参数组合，在仿真环境中进行实测，并根据踢球结果计算损失（Loss），从而找到最优参数。

## 核心组件

### 1. 优化目标
主要优化以下参数：
*   **球的定位限制 (`ball_limits`)**: 调整机器人踢球时相对于球的最佳位置范围。
*   **踢球方向偏差 (`kick_bias_dir`)**: 补偿踢球时的方向偏差。

### 2. `Kick` 类
用于执行具体的踢球测试：
*   **`kick_once(y, name)`**: 
    *   初始化环境和球的位置。
    *   执行踢球动作序列（`Basic_Kick`）。
    *   等待球停止，并返回球的最终坐标。
*   **`set_slot` / `get_slot`**: 用于读写底层的动作槽（Slot）参数。

### 3. 损失函数 (`loss`)
评估一组参数的好坏：
*   **测试流程**: 使用当前参数连续进行 4 次踢球测试（不同初始位置）。
*   **损失计算**: `loss = ((20 - x) ** 2) * 0.6 + ((y * 3) ** 2) * 0.4`
    *   目标是让球踢得越远越好（X 接近 20）。
    *   目标是让球偏离中心越小越好（Y 接近 0）。
*   **优选策略**: 取 4 次测试中损失值最低的两次的平均值作为最终 Loss，以减少随机性影响。

### 4. 优化流程 (Main Loop)
*   **初始化**: 使用 `cmaes.CMA` 初始化优化器，或从 `optimizer_state.pkl` 加载之前的优化状态。
*   **种群迭代**:
    1.  `optimizer.ask()`: 生成一组候选参数。
    2.  应用参数到机器人。
    3.  运行 `loss()` 获取评估结果。
    4.  `optimizer.tell()`: 将评估结果反馈给优化器。
    5.  保存优化状态和结果到文件。
*   **结果记录**: 
    *   `result.txt`: 记录每一代的参数、Loss 值以及踢球坐标。
    *   `optimizer_state.pkl`: 保存优化器状态以便断点续传。

## 使用说明

1.  **环境准备**: 确保仿真服务器已启动，并安装了必要的 Python 包 (`cmaes`, `numpy` 等)。
2.  **运行**: 直接运行脚本 `python 优化_cma_train_t长踢的定位和bias.py`。
3.  **结果**: 
    *   程序会自动进行迭代优化。
    *   最终的最优参数会输出在控制台并记录在 `result.txt` 末尾。
