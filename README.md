# 基于CMA-ES的机器人踢球参数优化

## 项目背景
RoboCup足球机器人仿真3D组比赛，需要优化机器人踢球参数以提高射门精度和距离。

## 核心工作

### 算法原理
使用CMA-ES（协方差矩阵自适应进化策略）进行黑箱优化：
采样参数 → 仿真测试 → 损失评估 → 自适应调整步长/方向 → 迭代寻优

### 优化目标
- ball_limits：踢球时相对于球的最佳位置范围
- kick_bias_dir：踢球方向偏差补偿

### 损失函数设计
loss = ((20-x)² × 0.6 + (y×3)² × 0.4)

- x：球最终位置（距离优先，权重0.6）
- y：偏离中心距离（精度兼顾，权重0.4）

### 稳健性处理
每次评估进行4次不同位置测试，取最优2次损失的平均值，减少随机性影响。
