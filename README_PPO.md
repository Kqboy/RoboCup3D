# PPO 强化学习踢球训练 (Kick Training with PPO)

本项目实现了基于 PPO (Proximal Policy Optimization) 算法的机器人踢球动作训练环境。代码位于 `kick.py`。

## 功能概述

该项目定义了一个符合 OpenAI Gym 标准的自定义环境 `Kick`，用于通过强化学习训练机器人（Agent）执行踢球任务。

## 核心组件

### 1. 环境类 (`Kick`)
继承自 `gym.Env`，实现了强化学习环境的标准接口：

*   **初始化 (`__init__`)**:
    *   连接服务器和监视器。
    *   初始化机器人 Agent (基于 `agent.Base_Agent`)。
    *   定义观察空间 (`observation_space`)：包含基础状态、关节信息和球的信息。
    *   定义动作空间 (`action_space`)：控制机器人的关节。
    *   设置踢球动作参数 (`Kick_Motion`)。

*   **重置 (`reset`)**:
    *   随机化球和机器人的初始位置。
    *   执行一系列稳定动作（如 `Zero_Bent_Knees`）。
    *   控制机器人走向球，直到达到适合踢球的位置和状态（距离、角度满足要求）。
    *   返回初始观察值。

*   **观察 (`observe`)**:
    *   收集并归一化环境状态数据，包括：
        *   **基础状态**: 步数计数、头部高度/速度、IMU数据（翻滚/俯仰）、陀螺仪、加速度计、足部压力传感器。
        *   **关节状态**: 20-22 个关节的位置和速度。
        *   **球相关信息**: 球相对于躯干/髋部的位置、速度、距离，以及踢球方向偏差。
    *   返回 维度为 `base_obs_size + joint_obs_size + ball_obs_size` 的一维向量。

### 2. 依赖库
*   `gym`: 强化学习环境标准接口。
*   `stable_baselines3`: 提供 PPO 算法实现。
*   `numpy`: 数值计算。
*   项目内部库: `agent`, `behaviors`, `world`, `scripts`, `math_ops` 等。

## 使用说明

该脚本设计为可直接与 `stable_baselines3` 的 `PPO` 算法配合使用。环境实例化时会自动连接到仿真服务器，并在训练过程中控制机器人与环境交互。

## 关键参数
*   **机器人类型**: 支持不同类型的机器人（如 Type 4 和其他），关节数量会有所不同（22 或 20 个）。
*   **观察空间维度**: 约 70+ 维（取决于具体配置）。
*   **动作空间**: 对应机器人的关节数量。
